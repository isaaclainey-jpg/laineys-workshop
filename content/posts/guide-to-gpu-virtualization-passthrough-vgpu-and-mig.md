## GPU Passthrough: What It Is and How It Works

GPU passthrough is a method that allows a physical GPU to be assigned directly to a virtual machine. This gives the VM exclusive access to the GPU's resources. A Guide to GPU virtualization: passthrough, vGPU, and MIG explains how this technique is used in environments that require full GPU performance.

Passthrough is ideal for applications like gaming, 3D rendering, and AI training. It ensures that the GPU's power is not shared, which can lead to better performance. ## vGPU: Virtual GPU Technology Explained

Virtual GPU technology, or vGPU, allows a single physical GPU to be split into multiple virtual GPUs. Each virtual GPU can be assigned to a different VM.
